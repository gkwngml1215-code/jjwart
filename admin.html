SEO / GEO 코드 생성기 — 값 입력 → 코드 생성 → 복사해서 붙여넣기

← 랜딩페이지로
이 페이지는 코드를 생성만 하는 정적 도구입니다. 입력한 값은 저장되지 않고 이 브라우저에만 임시 보관되며(새로고침해도 유지, 다른 기기·사람과는 공유되지 않음), 실제 사이트에 반영하려면 오른쪽에서 생성된 코드를 복사해 아래 안내대로 직접 파일에 붙여넣어야 합니다.
  • SEO 메타태그 → index.html의 <head> 안, 기존 title/description/keywords 부분을 교체
  • 구조화 데이터(JSON-LD) → index.html의 </head> 직전에 추가
  • robots.txt / llms.txt / sitemap.xml → 다운로드 버튼으로 받아서 프로젝트 최상위(루트) 폴더에 그대로 저장
1. 기본 SEO
2. Open Graph / Twitter 카드
3. 병원 정보 (구조화 데이터 기초)
4. 진료시간
5. 자주 묻는 질문 (FAQPage)
6. AI 크롤러 허용 (GEO / robots.txt)

체크하면 해당 AI가 사이트를 읽어 답변에 인용할 수 있도록 허용(Allow)합니다. 체크를 풀면 차단(Disallow)됩니다.

7. llms.txt / sitemap.xml
8. 원장 컬럼 (SEO / GEO)

컬럼을 선택해 편집하면 우측 [컬럼 페이지] 탭에 완성된 HTML 파일이, [컬럼 목록 카드] 탭에 columns.html에 붙여넣을 카드 코드가 생성됩니다. 컬럼을 추가·수정하면 sitemap.xml과 llms.txt에도 자동으로 반영됩니다.

다 쓰셨으면 화면 맨 아래 [홈페이지에 바로 반영] 을 누르세요
