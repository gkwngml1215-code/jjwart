8. 원장 컬럼은 홈페이지(GitHub 저장소)에 올라가 있는 목록을 기준으로 동작합니다. 발행할 때마다 홈페이지의 최신 목록을 먼저 불러와, 지금 쓰는 글 1개만 추가·수정하고 나머지 글은 그대로 둡니다. 다른 기기·다른 브라우저·시크릿 창에서 열어도 이전 글은 사라지지 않습니다.

1~7번은 코드를 생성만 하는 도구입니다. 입력값은 이 브라우저에만 보관되며, 실제 사이트에 반영하려면 오른쪽에서 생성된 코드를 복사해 아래 안내대로 직접 파일에 붙여넣어야 합니다.

  • SEO 메타태그 → index.html의 <head> 안, 기존 title/description/keywords 부분을 교체
  • 구조화 데이터(JSON-LD) → index.html의 </head> 직전에 추가
  • robots.txt → 다운로드 버튼으로 받아서 프로젝트 최상위(루트) 폴더에 저장 (sitemap.xml·llms.txt의 컬럼 목록은 발행할 때 자동으로 갱신됩니다)
